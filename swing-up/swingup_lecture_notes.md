# Swing-up 제어: 에너지 공급에서 균형 유지까지

이 자료는 [`swingup_control.py`](./swingup_control.py)의 구현을 바탕으로 회전형 역진자의 Swing-up 원리와 제어 흐름을 설명한다. 상태 추정과 균형 제어는 [`balance_control.py`](./balance_control.py), 모터 구동은 [`SwingupController.ino`](./SwingupController/SwingupController.ino)를 함께 참고한다.

Swing-up은 **아래에 매달린 진자를 반복해서 흔들어 에너지를 높인 뒤, 위쪽에 도달하면 균형 제어로 전환하는 방식**이다. 그네를 타면서 적절한 순간에 힘을 주어 진폭을 키우는 원리와 비슷하다.

## 1. 제어 대상과 입력

모터는 수평으로 회전하는 암을 움직이고, 암에 연결된 진자는 그 움직임에 의해 흔들린다. 제어 입력은 **암의 각가속도**이다.

| 기호 | 코드 변수 | 의미 | 단위 |
|---|---|---|---|
| $\theta$ | `th` | 위쪽 수직 자세를 기준으로 한 진자 각도 | rad |
| $\dot\theta$ | `w` | 진자 각속도 | rad/s |
| $\phi$ | `phi` | 모터 암의 원점 기준 각도 | rad |
| $\dot\phi$ | `phid` | 모터 암의 각속도 | rad/s |
| $u=\ddot\phi$ | `u` | 명령할 모터 암의 각가속도 | rad/s² |

각도 기준은 다음과 같다.

- $\theta=0$: 진자가 위로 선 상태
- $\theta=\pm\pi$: 진자가 아래로 매달린 상태

엔코더는 아래쪽을 약 0°로 읽으므로, 코드에서는 `bc.Estimator(180.0)`으로 기준을 위쪽으로 바꾼다. 이후 `b_hat`으로 수직 기준의 작은 오차를 보정한다.

```python
est = bc.Estimator(180.0)
th_raw, w, phi, phid = x
th = bc.wrap_rad(th_raw - b_hat)
```

진자 각속도 `w`는 엔코더 각도를 차분하고 저역통과 필터를 적용해 추정한다. 암의 위치와 속도는 펌웨어가 보내는 스텝 기반 정보를 사용한다.

## 2. Swing과 Balance를 나누는 이유

아래에 매달린 진자를 위쪽에 세우려면 큰 각도 범위에서 움직여야 한다. 반면 위쪽에서 균형을 유지하는 제어기는 수직 부근의 작은 움직임을 다루도록 설계된다.

따라서 이 코드는 두 제어기를 전환한다.

```mermaid
flowchart LR
    A["아래에 매달린 상태"] --> B["초기 흔들기"]
    B --> C["Swing: 에너지 공급"]
    C -->|"위쪽 근처 + 속도 조건 + 암 위치 조건"| D["Balance: 균형 유지"]
    D -->|"진자 기울기 30° 초과"| C
```

이처럼 상태에 따라 서로 다른 제어 법칙을 사용하는 구조를 **하이브리드 제어**라고 한다.

## 3. Swing-up의 목표: 위쪽까지 올라갈 에너지 확보

코드는 진자의 에너지를 다음과 같이 계산한다.

```python
E = 0.5 * w * w + A_G * (math.cos(th) - 1)
```

$$
E=\frac{1}{2}\dot\theta^2+A_G(\cos\theta-1),
\qquad A_G=\frac{3g}{2l}
$$

여기서 $E$는 **관성모멘트로 정규화하고, 위쪽 정지 상태를 0으로 정한 에너지**이다. 줄(J) 단위의 실제 에너지와는 구별해야 한다. $l$은 이 단순화된 균일 막대 모델의 진자 길이이다.

| 진자 상태 | 에너지 |
|---|---:|
| 위쪽에서 정지: $\theta=0,\;\dot\theta=0$ | $E=0$ |
| 아래쪽에서 정지: $\theta=\pi,\;\dot\theta=0$ | $E=-2A_G$ |
| 같은 각도에서 더 빠르게 움직임 | 운동에너지 증가 |

구현에서는 자유진동으로 식별한 고유진동수 `WN = 7.499`를 이용해 `A_G = WN ** 2`로 설정한다. 따라서 $A_G\approx56.24$이고, 아래쪽 정지 상태의 에너지는 약 $-112.47$이다.

스윙업은 다음 변화가 일어나도록 만드는 과정이다.

$$
\boxed{E\approx-112.47\quad\longrightarrow\quad E\approx0}
$$

기본 목표값 `etarget`은 정확히 0보다 조금 큰 **1.0**이다. 이상적인 위쪽 도달 에너지보다 약간의 여유를 둔 설정으로 해석할 수 있다.

## 4. 어느 방향으로 가속해야 에너지가 증가하는가?

코드가 바탕으로 사용하는 단순화된 진자 모델은 다음과 같다.

$$
\ddot\theta=A_G\sin\theta+b\cos\theta\,u-C_D\dot\theta
$$

여기서 $b>0$는 암의 가속도가 진자에 전달되는 정도이고, $C_D$는 감쇠 계수이다. 코드의 기본값은 $b=0.730$이며, $C_D=2\zeta\omega_n$이다.

에너지 식을 시간에 대해 미분하면 다음을 얻는다.

$$
\begin{aligned}
\dot E
&=\dot\theta\ddot\theta-A_G\sin\theta\,\dot\theta\\
&=b\dot\theta\cos\theta\,u-C_D\dot\theta^2
\end{aligned}
$$

첫 번째 항은 **모터 입력이 공급하거나 빼앗는 에너지**, 두 번째 항은 **감쇠에 의한 손실**이다. 이 관계는 위의 단순화된 모델에서 유도되며, 실제 장치의 모든 비선형 효과를 포함하는 식은 아니다.

모터 입력이 에너지를 공급하려면 다음 조건이 필요하다.

$$
\dot\theta\cos\theta\,u>0
$$

즉, **입력 $u$의 부호를 $\dot\theta\cos\theta$의 부호에 맞추는 것**이 핵심이다.

```python
s = w * math.cos(th)
```

단순히 진자가 움직이는 방향만 보는 것이 아니라, 현재 진자 각도에 따라 암의 가속도가 전달되는 방향도 함께 고려한다.

## 5. 실제 Swing 제어식

실제 제어 입력은 에너지 공급과 암의 움직임 억제를 함께 고려한다.

```python
s = w * math.cos(th)
scale = min(1.0, max(0.0, args.ke * (args.etarget - E)))
u = (
    args.pump * scale * (1.0 if s > 0 else -1.0)
    - args.kda * phid
    - args.kpa * phi
)
```

$$
\boxed{
u=P\,\alpha(E)\,\sigma(\dot\theta\cos\theta)
-k_{da}\dot\phi-k_{pa}\phi
}
$$

$$
\alpha(E)=\operatorname{clip}\left(k_E(E_{\mathrm{target}}-E),0,1\right)
$$

코드의 $\sigma(s)$는 $s>0$이면 $+1$, 그 외에는 $-1$이다.

| 항 | 기본값 | 역할 |
|---|---:|---|
| $P$: `pump` | 30 rad/s² | 에너지를 공급하는 가속도 크기 |
| $k_E$: `ke` | 0.3 | 에너지 부족량을 펌핑 강도로 변환 |
| $k_{da}$: `kda` | 5.0 | 암이 너무 빠르게 움직이지 않도록 억제 |
| $k_{pa}$: `kpa` | 3.0 | 암이 원점에서 멀어지는 것을 억제 |

각 항의 의미는 다음과 같다.

1. **에너지 공급 항** $P\alpha(E)\sigma(\dot\theta\cos\theta)$: 에너지가 많이 부족하면 `scale = 1`이 되어 거의 일정한 크기의 가속도를 양·음으로 전환한다. 목표에 가까워지면 펌핑 강도를 줄인다.
2. **암의 속도 억제 항** $-k_{da}\dot\phi$: 암의 움직임을 감쇠한다.
3. **암의 원점 복귀 항** $-k_{pa}\phi$: 암이 한쪽으로 계속 이동하는 것을 억제한다.

강의에서는 다음 두 가지를 구분해야 한다.

- 목표 에너지를 넘으면 **펌핑 항은 0**이 된다. 이 항이 반대 부호로 바뀌어 적극적으로 에너지를 제거하는 구조는 아니다.
- 에너지 증가 방향을 선택하는 것은 펌핑 항이다. 암의 위치·속도 보정과 마찰까지 포함하면 **전체 에너지가 매 순간 증가한다고 보장되지는 않는다.**

## 6. 초기 흔들기

진자가 정확히 아래에서 정지해 있으면 $\dot\theta=0$이므로 처음에는 에너지 전달률도 0이다. 코드는 먼저 일정한 입력으로 움직임을 만든다.

```python
if t < 0.15:
    u = args.pump
elif t < 0.30:
    u = -args.pump
else:
    # 에너지 기반 제어
```

| 시간 | 기본 입력 |
|---|---:|
| 0~0.15초 | +30 rad/s² |
| 0.15~0.30초 | −30 rad/s² |
| 0.30초 이후 | 에너지 기반 제어 |

이상적으로 두 구간의 가속도 적분은 상쇄되므로 암의 속도가 초기값으로 돌아온다. 다만 **암의 위치까지 원래대로 돌아오는 것은 아니다.**

이 초기 입력은 실행 시작 시에만 적용된다. 균형을 잃어 다시 `swing`으로 전환될 때는 에너지 기반 제어로 바로 들어간다.

## 7. 위쪽에서 잡기: Balance로 전환

기본 설정에서는 다음 조건을 모두 만족하면 균형 제어로 전환한다.

$$
t>0.3\text{ s},\qquad
|\theta|<12^\circ,\qquad
|\dot\theta|<4\text{ rad/s},\qquad
|\phi|<60^\circ
$$

- **진자 각도 조건:** 위쪽에 충분히 가까워야 균형 제어가 가능하다.
- **진자 속도 조건:** 위쪽을 너무 빠르게 통과하면 잡아 세우기 어렵다.
- **암 위치 조건:** 회전 한계까지 남은 공간이 있어야 균형을 잡기 위한 추가 움직임이 가능하다.

전환 후에는 4개 상태를 이용하는 피드백 제어를 사용한다.

```python
u = float(-K @ np.array([th, w, phi - phi_ref, phid]))
```

$$
u=-K
\begin{bmatrix}
\theta\\
\dot\theta\\
\phi-\phi_{\mathrm{ref}}\\
\dot\phi
\end{bmatrix}
$$

이득 $K$는 `balance_control.py`의 `place4()`에서 수직 부근의 선형 모델을 이용해 극 배치로 구한다. `swingup_control.py`의 기본 극은 다음과 같다.

$$
-6\pm6j,\qquad -1.5\pm1j
$$

균형 제어로 전환하는 순간에는 현재 암 위치를 목표 위치로 정한다.

```python
mode, phi_ref = "balance", phi
```

이후 목표를 시간상수 3초로 서서히 원점에 이동시킨다.

```python
phi_ref *= math.exp(-period / 3.0)
```

진자를 잡는 순간 암을 급하게 원점으로 움직이지 않고, 먼저 균형을 확보한 뒤 돌아오도록 하는 설계이다.

균형 유지 중 진자 기울기가 30°를 넘으면 다시 Swing 제어로 전환한다. 진입 기준 12°와 이탈 기준 30°를 다르게 두는 **히스테리시스**는 경계에서 모드가 자주 바뀌는 것을 줄인다.

## 8. Python에서 펌웨어까지의 제어 경로

Python은 기본적으로 100Hz, 약 10ms 주기를 목표로 상태를 받아 가속도를 계산한다. 실제 주기는 통신 및 실행 시간의 영향을 받는다.

```python
pps2 = float(np.clip(
    u * bc.PPS2_PER_RAD,
    -bc.ACCEL_MAX_PPS2,
    bc.ACCEL_MAX_PPS2
))
resp = link.step(bc.CMD_SET_ACCEL, pps2)
```

모터 1회전은 3200 마이크로스텝이므로 다음과 같이 단위를 변환한다.

$$
a_{\mathrm{pps^2}}=u_{\mathrm{rad/s^2}}\frac{3200}{2\pi}
$$

예를 들어 30 rad/s²는 약 15,279 pps²이다. 최종 명령은 ±24000 pps²로 제한된다. `pump`는 펌핑 항의 크기이며, 암의 위치·속도 보정까지 합한 최종 `u`는 이와 다를 수 있다.

펌웨어는 명령 번호 1로 받은 `action[0]`을 가속도로 저장한다.

```cpp
case CMD_SET_ACCELERATION:
  timeout_latched = false;
  accel_command_pps2 = action[0];
  break;
```

그리고 MCU 내부에서 가속도를 적분해 목표 속도를 갱신한다.

$$
v_{k+1}=v_k+a_k\Delta t
$$

```cpp
target_velocity_pps += a * dt;
apply_target_velocity(target_velocity_pps);
```

계산한 속도는 모터 방향과 스텝 펄스 주파수로 적용된다. 가속도 0은 정지 명령이 아니라 목표 속도를 유지하는 명령이다.

```text
진자 각도와 암 상태 수신
          ↓
상태 추정 및 에너지 계산
          ↓
Swing / Balance 모드 선택
          ↓
암의 각가속도 u 계산
          ↓
rad/s² → pps² 변환 및 제한
          ↓
시리얼로 펌웨어에 전송
          ↓
펌웨어에서 가속도 적분 → 스텝 속도 적용
```

## 9. 실제 장치를 위한 보정과 보호

### 수직 기준 보정

정지 마찰 때문에 진자가 멈춘 위치가 정확한 수직과 조금 다를 수 있다. `calibrate_centre()`는 작은 암 움직임으로 자유진동을 발생시키고, 여러 시간 창에서 측정한 최대·최소 각도의 중간값을 구한다. 그 중간값들의 중앙값으로 수직 기준을 추정한다.

이 보정용 입력은 `+a`를 T 동안, `−a`를 2T 동안, `+a`를 T 동안 적용하는 형태이다. 앞서 설명한 스윙업 시작의 두 구간 입력과 달리, 이상적인 조건에서는 암의 위치와 속도를 모두 시작 상태로 돌려놓는다.

균형 유지 중에는 암의 목표 위치와 실제 위치 사이의 편차를 이용해 `b_hat`을 천천히 보정한다.

```python
b_hat += gamma * (phi - phi_ref) * period
b_hat = max(-math.radians(5), min(math.radians(5), b_hat))
```

이는 암의 지속적인 위치 편차가 수직 기준 오차에서 비롯될 수 있다는 가정에 기초한 보정이며, 보정 범위는 ±5°이다.

### 구동 보호와 기록

| 항목 | 구현 동작 |
|---|---|
| 암 회전 제한 | Python 기본 ±140°, 펌웨어 ±150° |
| 가속도 제한 | 최종 명령 ±24000 pps² |
| 속도 제한 | 펌웨어 목표 속도 ±4000 pps |
| 통신 중단 | 펌웨어가 150ms 넘게 정상 호스트 명령을 받지 못하면 정지 |

| 드라이버 보호 | 펌웨어 보호 상태가 보고되면 종료 |
| 사용자 중단 | Ctrl+C 또는 종료 처리에서 정지 명령 전송 |

위 수치는 해당 코드의 기본 설정이며 장치의 일반적인 허용 범위를 뜻하지 않는다.

## 10. 강의에서 강조할 핵심

> Swing-up은 진자의 움직임과 위치에 맞춰 암을 가속하여 에너지를 공급하고, 진자가 위쪽에 충분히 가깝고 속도가 적절해지면 상태 피드백 제어로 전환해 균형을 유지하는 과정이다.

학생들이 설명할 수 있어야 할 질문은 다음과 같다.

1. 왜 진자 각도뿐 아니라 각속도도 알아야 하는가?
2. 입력 부호를 결정할 때 왜 $\dot\theta\cos\theta$를 사용하는가?
3. 에너지가 위쪽 도달 수준에 이르렀다는 것만으로 균형 유지가 보장되지 않는 이유는 무엇인가?

5. Swing 진입·이탈 조건을 서로 다르게 설정한 이유는 무엇인가?
