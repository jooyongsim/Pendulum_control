## 3. 모델과 추정 방법

### 3.1 지배 방정식

피벗이 고정된 진자의 운동 방정식은

$$\ddot{\theta} + 2\sigma\,\dot{\theta} + \omega_0^2 \sin\theta = 0,
\qquad \omega_0^2 = \frac{m g l}{J}$$

여기서 $\theta$는 매달림 평형점에서 잰 각도, $l$은 피벗에서 질량중심까지 거리,
$J$는 피벗 기준 관성모멘트다. 소각도에서 $\sin\theta \approx \theta$이면 표준 2차계가 된다.

$\omega_0$만으로는 $m$, $l$, $J$를 따로 분리할 수 없고, 결정되는 것은 이들의 조합인
**유효 길이**뿐이다.

$$L_{\text{eff}} \equiv \frac{g}{\omega_0^2} = \frac{J}{m l}$$

### 3.2 주기 추정 — 왜 차분하지 않는가

인접 피크의 시간 차로 주기를 구하면 샘플링 지터가 그대로 들어온다. 반주기가 약 $0.42\ \mathrm{s}$
인데 폴링 주기가 $20\ \mathrm{ms}$이므로 **한 번의 차분마다 약 5%의 양자화 오차**가 생긴다.

대신 피크 **시각**을 피크 **인덱스**에 선형 회귀시킨다. 기울기가 반주기이고, 회귀가 지터를
평균내므로 훨씬 안정적이다.

$$t_k \approx t_0 + \frac{T_0}{2}\,k \quad\Longrightarrow\quad T_0 = 2 \cdot \text{slope}$$

또한 대진폭에서는 주기가 길어진다. 1차 보정은

$$T(A) \approx T_0\left(1 + \frac{A^2}{16}\right)$$

이고, 실제로 93° 릴리스에서 전체 평균 주기가 $0.8664\ \mathrm{s}$로, 40° 릴리스의
$0.8433\ \mathrm{s}$보다 길게 측정되었다. 따라서 $\omega_0$ 추정에는 **진폭 25° 미만의 피크만**
사용한다.

> 초기 분석에서 $T$를 $A^2$에 회귀시켜 $A \to 0$으로 외삽했더니 1.29 Hz가 나왔는데,
> 이는 노이즈를 과적합한 결과였다. 소진폭 구간만 쓰는 방식이 세 구간에서 일관되게
> 1.194 Hz를 준다.

### 3.3 마찰 모델 — 점성과 쿨롱의 분리

두 마찰은 **진폭 포락선의 모양이 다르다.**

- 점성 마찰: 감쇠력이 속도에 비례 → 포락선이 **지수** 감소
- 쿨롱(건)마찰: 감쇠력 크기가 일정 → 포락선이 **선형** 감소

둘을 함께 두면 진폭 $A$의 감소율은

$$\frac{dA}{dt} = -(\sigma A + c)$$

이고, 이를 풀면

$$A(t) = \left(A_0 + \frac{c}{\sigma}\right) e^{-\sigma t} - \frac{c}{\sigma}$$

이 식은 $\sigma$를 고정하면 나머지에 대해 **선형**이다. 따라서 $\sigma$를 스캔하면서
$2 \times 2$ 정규방정식을 닫힌 형태로 풀어 최적해를 찾는다.

## 4. 결과

### 4.1 고유 진동수와 유효 길이

| 릴리스 | $T_0$ | $f_0$ | $\omega_0$ | $L_{\text{eff}}$ |
| --- | --- | --- | --- | --- |
| 40.7° | 0.8372 s | 1.1944 Hz | 7.505 rad/s | 174.1 mm |
| 93.5° | 0.8362 s | 1.1959 Hz | 7.514 rad/s | 173.7 mm |
| 43.7° | 0.8376 s | 1.1939 Hz | 7.502 rad/s | 174.3 mm |

$$\boxed{\ \omega_0 = 7.508\ \mathrm{rad/s}, \qquad L_{\text{eff}} = 174\ \mathrm{mm}\ }$$

초기 진폭이 40°에서 93°까지 두 배 이상 차이나는데도 편차가 0.09%다. 추정기가 대진폭
효과를 제대로 걸러내고 있다는 뜻이다.

유효 길이에서 실제 치수를 역산하려면 질량 분포 가정이 필요하다.

- 끝점에서 회전하는 **균일 막대**: $J = \tfrac{1}{3}mL^2$, $l = L/2$ 이므로
  $L_{\text{eff}} = \tfrac{2}{3}L$, 즉 $L = 1.5 \times 174 = \mathbf{261\ mm}$
- 가벼운 봉 끝의 **점질량**: $L = L_{\text{eff}} = \mathbf{174\ mm}$

실제 진자는 이 둘 사이에 있다.

### 4.2 마찰

포락선 적합도를 세 모델로 비교하면 다음과 같다.

| 모델 | 포락선 모양 | $R^2$ |
| --- | --- | --- |
| 점성만 | 지수 | 0.894 |
| 쿨롱만 | 선형 | 0.975 |
| **점성 + 쿨롱** | 혼합 | **0.994** |

**건마찰이 지배적**이다. 이는 베어링 마찰이 주된 손실원임을 뜻하며, 다음 두 관측과 일치한다.

1. 로그 후반에서 진자가 0°가 아니라 **2.4°에서 멈췄다.** 쿨롱 마찰은 정지 마찰 데드밴드
   안 어디에서든 정지할 수 있으므로, 평형점에 정확히 수렴하지 않는다.
2. 진폭이 작아질수록 선형 감소가 두드러진다.

다만 $\sigma$와 $c$의 **분배는 잘 결정되지 않는다.** 구간별로 $\sigma$가
$0.015$–$0.119\ \mathrm{s^{-1}}$로 흩어지는 반면 합산 포락선은 항상 $R^2 > 0.99$로 잘 맞는다.
두 파라미터가 상관되어 있기 때문이며, **합쳐진 감쇠는 신뢰할 수 있지만 개별 값은 그렇지 않다.**

## 5. 검증 — 피팅이 아닌 순방향 적분

동정된 파라미터로 비선형 방정식을

$$\ddot{\theta} = -\omega_0^2 \sin\theta - 2\sigma\dot{\theta} - F\,\mathrm{sgn}(\dot{\theta})$$

적분해서(측정된 극점에서 $\dot\theta = 0$으로 시작) 93° 릴리스 실측과 비교했다.
쿨롱 항은 주기당 진폭 손실 $4F/\omega_0^2$ 관계로 $c$에서 환산한다.

진동자에서는 점대점 RMS가 **누적 위상 오차**에 지배되므로, 진폭과 위상을 분리해서 본다.

| 지표 | 값 |
| --- | --- |
| 비교한 피크 수 | 28개 (89° → 12°) |
| 주파수 오차 | $-0.64\%$ (12초에 걸쳐) |
| 진폭 오차 (전체) | RMS 9.2°, 최대 20.6° |
| 진폭 오차 (50° 미만 19개 피크) | RMS 6.8°, 최대 10.9° |

주파수는 12초 동안 0.64%만 어긋나 잘 맞는다. 진폭 오차가 남는 이유는 두 가지다.

1. **대진폭에서 모델이 과도하게 감쇠시킨다.** 첫 스윙(89°)에서 −16°로 가장 크고, 진폭이
   줄수록 급격히 작아진다. 점성+쿨롱으로 설명되지 않는 **진폭 의존 감쇠**(고속 구간의
   공기저항 등)가 남아 있다는 신호다.
2. **실측 진동 자체가 비대칭이다.** 양의 피크 평균이 35.5°, 음의 피크 평균이 42.3°로
   **17.4% 비대칭**이다. 대칭 모델은 원리적으로 이를 재현할 수 없다. 장비가 약간
   기울어져 있거나 피벗에 정적 오프셋이 있을 가능성이 높다.

즉 **감쇠의 크기는 맞지만 형태에 개선 여지가 있다.** 밸런싱 제어는 소각도 영역에서
동작하므로 실용상 문제가 되지 않는다.

## 6. 제어 설계용 선형 모델

$\theta$를 해당 평형점에서 잰 각도라 할 때,

**매달림 평형점** (안정):

$$\ddot{\theta} = -56.37\,\theta - 0.160\,\dot{\theta}
\qquad s = -0.080 \pm j\,7.508$$

**직립 평형점** (불안정) — $\sin\theta$의 부호가 뒤집혀 복원력이 발산력이 된다:

$$\ddot{\theta} = +56.37\,\theta - 0.160\,\dot{\theta}
\qquad s = +7.428,\ -7.588$$

상태공간으로 쓰면 $\mathbf{x} = [\theta,\ \dot{\theta}]^{T}$에 대해

$$\dot{\mathbf{x}} =
\begin{bmatrix} 0 & 1 \\ +\omega_0^2 & -2\sigma \end{bmatrix} \mathbf{x}
+ \begin{bmatrix} 0 \\ b \end{bmatrix} u$$

입력 계수 $b$(로터 가속도가 진자에 주는 토크)는 **이 데이터에 들어 있지 않다.**
자유 진동만 기록했으므로 $u \equiv 0$이기 때문이다. 7절 참고.

### 설계 함의

불안정 극점이 $+7.43\ \mathrm{rad/s}$라는 것은 다음을 뜻한다.

$$\tau = \frac{1}{7.43} = 135\ \mathrm{ms} \quad (\text{e배 발산}),
\qquad t_{2\times} = \frac{\ln 2}{7.43} = 93\ \mathrm{ms}$$

- **샘플링**: 현재 50 Hz는 불안정 시상수당 6.7 샘플에 불과하다. 동작은 하지만 여유가 없으므로
  밸런싱에는 **100–200 Hz**를 권한다.
- **속도 추정**: 0.3° 분해능에서 50 Hz 차분은 $0.3/0.02 = 15\ \mathrm{deg/s}$의 양자화 잡음을
  만든다. 미분 이득에 그대로 증폭되므로 필터링이 필수다.
- **정상상태 오차**: 건마찰 데드밴드 때문에 적분 항 없이는 각도 오차가 남는다. 다만 불안정
  플랜트에 적분기를 더하면 위상 여유가 줄어드니 주의해야 한다.

## 7. 한계와 다음 단계

이 분석으로 결정된 것과 아닌 것을 구분해 둔다.

**결정된 것**

- 진자의 $\omega_0$와 $L_{\text{eff}}$ — 0.09% 재현성
- 마찰의 성격(건마찰 지배)과 전체 감쇠량

**결정되지 않은 것**

- $m$, $l$, $J$ **개별 값** — $\omega_0$는 $mgl/J$ 조합만 준다. 분리하려면 질량과 치수를
  직접 재거나, 알려진 관성을 추가해 진동수 변화를 측정해야 한다.
- $\sigma$와 $c$의 **분배** — 상관이 커서 개별 값은 신뢰하기 어렵다.
- **입력 계수 $b$** — 자유 진동 데이터에는 없다. `acceleration_control.ipynb`의 개루프
  가진 데이터로 구해야 한다.
- **로터 동역학** — 스테퍼의 가속 명령에서 실제 각도까지의 전달함수는 별도 문제다.

**권장하는 다음 실험**

1. 로터에 알려진 가속도 처프/스텝을 주고 진자 응답을 기록해 $b$를 동정한다.
2. 비대칭 17.4%의 원인을 확인한다. 장비 수평을 맞춘 뒤 다시 자유 진동을 기록하면
   비대칭이 줄어야 한다.
3. 소진폭(10° 미만)에서 장시간 기록해 쿨롱 데드밴드 크기를 직접 측정한다.

## 8. 재현 방법

```bash
# 기본: data/encoder_log_*.csv 전부 분석하고 그림 2장 생성
python pendulum_model_id.py

# 특정 로그만
python pendulum_model_id.py --glob "data/encoder_log_20260914_2119*.csv"

# 창을 띄우지 않고 저장만
python pendulum_model_id.py --no-plots
```

스크립트는 구간 분리 → 파라미터 추정 → 통합 모델 → 순방향 적분 검증 순으로 출력한다.

> **구현 메모**: 포락선 피팅에 `scipy.optimize.curve_fit`을 쓰지 않는다. 이 환경의
> scipy 빌드에서 bounded 경로가 LAPACK `_compute_lwork` 안에서 프로세스를 죽인다
> (Windows fatal exception `0xc06d007f`). 앞서 설명한 대로 $\sigma$ 스캔 + 닫힌 형태
> 최소제곱으로 대체했으므로 numpy만 있으면 동작한다.
